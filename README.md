# \# STM32 15-Day Embedded Systems Challenge

# 

# A 15-day hands-on embedded systems development challenge using the \*\*STM32 NUCLEO-F401RE\*\*, \*\*STM32CubeIDE\*\*, \*\*STM32 HAL\*\*, and \*\*FreeRTOS\*\*.

# 

# The goal of this challenge was to build practical experience with microcontroller peripherals, communication protocols, sensors, debugging, watchdogs, memory, and real-time operating systems.

# 

# \## 🛠️ Hardware \& Tools

# 

# \- \*\*MCU:\*\* STM32F401RE

# \- \*\*Development Board:\*\* STM32 NUCLEO-F401RE

# \- \*\*IDE:\*\* STM32CubeIDE

# \- \*\*Framework:\*\* STM32 HAL

# \- \*\*RTOS:\*\* FreeRTOS

# \- \*\*Debugger:\*\* ST-LINK

# \- \*\*Terminal:\*\* Tera Term

# 

# \## 📚 15-Day Progress

# 

# | Day | Project | Topics Covered |

# |---|---|---|

# | 01 | GPIO | GPIO Output, LED Control, Button |

# | 02 | EXTI Interrupt | External Interrupts, NVIC |

# | 03 | Timer Interrupt | TIM2, Timer Interrupt |

# | 04 | UART | UART Communication, Serial Data |

# | 05 | UART LED | UART Commands, LED Control |

# | 06 | PWM | TIM1 PWM, LED Brightness Control |

# | 07 | ADC | Analog-to-Digital Conversion |

# | 08 | I2C LCD | I2C Communication, LCD |

# | 09 | DHT11 | Temperature \& Humidity Sensor |

# | 10 | RTC | Real-Time Clock, Time-Stamped Data |

# | 11 | SPI | SPI Communication |

# | 12 | IWDG / UART DMA | Watchdog, DMA, UART, CAN Concepts |

# | 13 | Flash Memory | Internal Flash Memory |

# | 14 | SmartSense | Sensor Monitoring, LCD, Buzzer |

# | 15 | FreeRTOS | Tasks, Scheduling, RTOS Concepts |
